# Software Requirements Specification

## 1. Purpose

The main purpose of this software, is to be able to visiualize and modify text files, new or old.

## 2. Scope

Supported:

- Work with plain-text files.
- Visiualize text files.
- Numbered lines
- Edit text files: Insert characters, new lines, tabs and delete them.
- Undo and Redo
- Create new text files.
- Files Path Control: Choose where to save and from where to open a file through the system path.
- Cursor Select 
- Arrow movement
- Manual saving
- Show Simple Error Codes to the user
- Basic Terminal Visualization
- Terminal line and the text file content separated
